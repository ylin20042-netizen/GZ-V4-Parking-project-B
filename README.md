# GZ Parking V4 Final

广州月保车位商业版开源项目。适合停车场月保车位展示、客户咨询承接、GitHub Pages 免费部署和开源学习。

## 功能

- 浅蓝冷色调商业官网布局
- 手机端响应式适配
- 停车场卡片展示
- 区域筛选
- 价格筛选
- 关键词搜索
- 只看有位
- 自动统计合作停车场、剩余车位、覆盖区域、最低月租
- 电话咨询按钮
- 微信号复制按钮
- 客户需求复制表单
- FAQ 常见问题
- JSON 数据管理

## 如何新增车位

打开 `data/parking.json`，复制一条数据并修改字段即可。

## 部署到 GitHub Pages

1. 上传全部文件到 GitHub 仓库
2. 打开 Settings → Pages
3. Source 选择 `Deploy from a branch`
4. Branch 选择 `main`
5. Folder 选择 `/ (root)`
6. 点击 Save

## 开源目标

该项目用于探索本地生活服务信息展示、停车场资源管理、静态网站数据管理和 AI 辅助开发工作流。
